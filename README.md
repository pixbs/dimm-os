# Dimm OS

The portfolio of Dimm, a product designer, built as an operating system: every page is a window on a desk, and on a phone every window is a drawer.

It is in development. The [milestones](https://github.com/pixbs/dimm-os/milestones) are the roadmap, and each step is an issue.

## Built with

Payload CMS 4, Next.js 16 and React 19 on Vercel, with Postgres on Neon. English and German.
